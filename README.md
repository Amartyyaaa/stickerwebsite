# PrintYourVibe

An online store for custom-printed stickers (2D and 3D), polaroids, wall posters, and laptop, fridge and diary stickers. It's built for India: prices in ₹, online payments through Razorpay (UPI, cards, netbanking) and Cash on Delivery.

## Status

**Step 0: choose a style.** `design/theme-showcase.html` shows eight storefront styles: Sticker Pop, Midnight Neon, Clean Gallery, Pastel Scrapbook, Desi Bazaar, Holo Y2K, Manga Ink and Retro Groovy. Each one is applied to the same sample home page, product grid, sticker-pack offer, custom studio and poster product page. Open the file in a browser and use the Desktop/Phone switch to compare. The artwork is generated placeholder art, and the prices and counts are samples.

## Build plan

1. **Foundation and storefront:**
   - Next.js and the database
   - a sample catalog of 5,000+ products
   - home page, listings with filters, search
   - product pages and cart
2. **Custom studio:**
   - builders for custom stickers, polaroids and posters
   - build-your-own sticker packs
3. **Accounts, checkout and payments:**
   - Razorpay and Cash on Delivery
   - order tracking
4. **Admin panel:**
   - products, including bulk CSV import
   - orders, offers and homepage content
5. **Launch readiness:**
   - SEO, speed and accessibility
   - end-to-end tests
   - a deployment guide
